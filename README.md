# Called It 🎯

A daily casual-forecasting game. Three binary predictions a day — Sports, Finance, Pop Culture —
dropped to everyone at the same moment with a hard 6-hour lock. Build per-category streaks, chase a
permanent lifetime score, and climb friends + global leaderboards.

> Full documentation (overview, architecture diagram, local dev/testing, admin guide) is below and in
> `/docs`. This repository contains the Azure-hosted backend, IaC, CI/CD, and mobile client scaffolds.
